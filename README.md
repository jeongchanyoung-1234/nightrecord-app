## 당신의 밤은, 어떤 기록을 남겼나

게임은 전적을 **최근 100판**만 남깁니다.  
**밤의 기록**은 `NR0000.sl2`를 브라우저에서 읽어, 그 한계를 넘는 **누적 전적·심도 레이팅·파티/보스 인사이트·유물 조합**까지 한곳에 모읍니다.

> 세이브 원본은 **내 브라우저에서만** 해독됩니다.  
> 로그인하면 분석된 원정 요약이 계정에 쌓이고, 원하는 프로필만 공개 검색에 올라갑니다.

**지금 바로:** [nightrecord.app](https://nightrecord.app) · [데모](https://nightrecord.app/?demo=1) · [원스토어 앱](https://m.onestore.co.kr/v2/ko-kr/app/0001012391)

## Features

### 전적 대시보드
- 개요 / 직업 / 보스 / 매칭 / 기록 탭
- 승률, 연승, 최종일 도달률, 평균 클리어 시간
- 최근 폼(W/L), 승률·참고 Elo 추이 그래프
- 심도 기록 레이팅 · 캐릭터별 peak

### 보스 & 파티
- 밤의 통치자별 승률 (기본 / Everdark 분리)
- 보스 × 내 직업 승률 매트릭스
- 자주 만난 동료 · 파티 직업 조합별 성적

### 공개 프로필
- `캐릭터이름#태그` 검색 · 자동완성
- 표시 태그 · 아바타 · 피크 레이팅 공개

### 유물 조합기
- 세이브에서 읽은 보유 유물로 로드아웃 추천
- 직업·빌드 맥락에 맞춘 조합 탐색 (로그인·본인 세이브)

### 계정
- 아이디/비밀번호 가입 · 로그인
- 게스트는 단발 분석, 로그인 시 누적·공개 동기화

## Quick start (players)

1. [nightrecord.app](https://nightrecord.app) 접속  
2. 게임 종료 후 세이브 복사  
   ```text
   %APPDATA%\Nightreign\<SteamID>\NR0000.sl2
   ```
3. 파일을 끌어다 놓기 → 전적 확인  
4. (선택) 가입 후 다시 분석하면 공개 검색·유물 조합기 사용  
5. (선택) [원스토어](https://m.onestore.co.kr/v2/ko-kr/app/0001012391)에서 앱 설치 후 같은 계정으로 로그인

세이브 없이 UI만 보려면 [`?demo=1`](https://nightrecord.app/?demo=1) 을 붙이세요.

## Repository note

이 공개 저장소는 **사이트 소개·UI·Android 앱 골격·배포 골격**을 담습니다.  
세이브 파서·유물 추천 가중치·내부 감사 자료 등 **운영 핵심 로직은 포함하지 않습니다.**  
실제 서비스는 [nightrecord.app](https://nightrecord.app) · [원스토어](https://m.onestore.co.kr/v2/ko-kr/app/0001012391)에서 이용해 주세요.

로컬에서 UI 골격만 보려면:

```bash
cp .env.example .env
docker compose up -d
# http://127.0.0.1:8080
```

## Stack (public surface)

- Web: Vanilla JS (ES modules), Chart.js, pako, PWA manifest/service worker  
- Server: Python `ThreadingHTTPServer` + SQLite  
- Android: Kotlin, Jetpack Compose, Room, Biometric, Glance widget  
- Deploy: Docker Compose · nginx · Let’s Encrypt
